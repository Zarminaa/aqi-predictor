# Data Collection

## Overview

The data collection stage is responsible for acquiring, organizing, and validating the historical weather and air quality data used throughout the AQI prediction pipeline.

Since meteorological observations and air pollution measurements are provided by separate services, they are collected independently before being merged into a unified dataset. This merged dataset forms the foundation for preprocessing, feature engineering, model training, and inference.

The project implements two complementary data ingestion workflows:

1. **Historical Data Collection**
   - Downloads the complete historical dataset from Open-Meteo APIs.
   - Generates the initial datasets used for exploratory analysis, feature engineering, and model training.

2. **Production Data Collection**
   - Automatically retrieves newly available observations every hour using Supabase Edge Functions.
   - Updates the database incrementally without downloading historical data again.

This design enables both reproducible offline model development and continuous production data ingestion.

# Data Sources

The project uses two publicly available APIs provided by **Open-Meteo**.

| Dataset | Source | Purpose |
|----------|--------|---------|
| Historical Weather | Open-Meteo Historical Weather API | Provides meteorological variables used as predictive features. |
| Air Quality | Open-Meteo Air Quality API | Provides AQI values and atmospheric pollutant concentrations. |

# Historical Data Collection

The initial version of the dataset is generated by downloading historical observations from the Open-Meteo APIs.

This one-time historical backfill creates the complete dataset used during model development.

## Collection Period

| Parameter | Value |
|-----------|--------|
| Start Date | 2022-08-05 |
| End Date | 2026-07-22 |
| Frequency | Hourly |
| Time Zone | UTC |

Both weather and pollution observations are collected using the same temporal range to ensure every record can later be matched using its timestamp.
